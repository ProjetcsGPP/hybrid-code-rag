# Resposta Esperada de um Novo Chat

Antes de iniciar qualquer análise o novo chat deverá confirmar explicitamente:

```text

ESTADO COMPREENDIDO
```

Caso essa confirmação não seja realizada, nenhuma proposta arquitetural deve ser considerada válida.
